DrinkingCraft
A datapack that turns Minecraft into a drinking game. Made for version 1.21.1, with ```"pack_format": 48```. Project inspired by the datapack "Drunkcraft", which is no longer available — this project aims to provide an updated, functional version. Originally made by EnzuBR.

## Rules
- Chance for everyone to drink when someone breaks a diamond, except the breaker (25%)
- Chance to choose someone to drink when breaking an emerald (7.5%)
- Chance to choose someone to drink when breaking a gold ore (7.5%)
- Chance to choose someone to drink when breaking an iron ore (4%)
- Chance to choose someone to drink when breaking a coal ore (3%)
- Chance to drink when breaking obsidian (5%)
- Chance to drink when obtaining your first Crafting Table (33%)

- Everyone drinks when the first person finds the mushroom biome, except the finder
- Everyone drinks when someone trades with a Villager for the first time
- Everyone drinks when the first person obtains a full diamond armor set, except that person
- Everyone drinks when the Nether is discovered
- Everyone drinks when a Nether Fortress is found
- Everyone drinks when the Stronghold is found
- Everyone takes a shot when the End is discovered
- Everyone takes a shot when the Ender Dragon is killed for the first time
- Everyone takes a shot when the first person obtains a full netherite armor set, except that person

- The first person to obtain an Ancient Debris chooses someone to take a shot
- The first person to obtain Return to Sender chooses someone to take a shot

- Chance to drink when killing a passive mob (5%)

- Finish your drink when you die
- Drink when you go 10 minutes without dying
- Drink when your equipment breaks

- Shot for the first player to obtain a Crafting Table
- Shot the first time you join the server
